# INFORMAÇÃO
Segundo orientado na seção [Instâncias](https://github.com/juanocv/listas_tdc/tree/main#inst%C3%A2ncias) do `README.md` principal, você deve fazer o download das instâncias `.col` através da página [Moodle da UFABC do Curso](https://moodle.ufabc.edu.br/course/view.php?id=4067) e movê-las para **esta pasta** a fim que o algoritmo as localize e aplique as implementações.

Os resultados de cada execução estarão na pasta [/lista2](https://github.com/juanocv/listas_tdc/tree/main/lista2/) em um arquivo `Results.txt` correspondente.
